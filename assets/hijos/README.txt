FOTOS DE LOS HIJOS
==================

1. Copia aquí las fotos (jpg o png). Sugerencia de nombres en minúscula y sin
   espacios ni tildes:  ana.jpg, jose.jpg, maria.jpg ...

2. Abre index.html, busca el array FAMILIA (cerca del inicio del <script>) y
   edita cada entrada:

   { nombre:"Ana", rol:"Hija", foto:"assets/hijos/ana.jpg" },

   - nombre : el nombre que se muestra en la tarjeta
   - rol    : texto pequeño dorado arriba del nombre (Hija, Hijo, Nieta, ...)
   - foto   : ruta a la imagen, o null si todavía no la tienes

3. Puedes agregar o quitar cuantas entradas quieras: la cuadrícula se ajusta
   sola y la animación de "reunión" se aplica automáticamente a las nuevas.

Formato ideal de la foto: vertical (proporción 3:4), cara centrada en la parte
superior. Si la foto es horizontal se recorta al centro.
